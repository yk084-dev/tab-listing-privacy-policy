Tab Listing プライバシーポリシー

最終更新日: 2026年10月5日

本ポリシーは、Chrome拡張機能「Tab Listing」（以下「本拡張機能」）が取り扱う情報、その利用目的、保存先、共有先について説明します。

本拡張機能は、タブの整理・保存・復元に必要な範囲で、開いているタブのURLとタイトル、タブグループ情報を扱います。情報は端末内に保存します。Chrome同期の設定保存と、利用者が任意に有効化するGoogle Drive同期を除き、開発者のサーバーへ送信しません。初回利用時に拡張機能内で説明を表示し、利用者の同意後にデータ処理を開始します。

1. 取り扱う情報

  • 開いているタブのURL、タイトル、タブID、ウィンドウID
  • タブグループの名前、色、およびグループに含まれるタブの情報
  • 保存したURLのURL、タイトル、アイコンURL、保存日時
  • 保存したグループの名前、色、各タブのURLとタイトル
  • 自動固定・除外ルールの名前やURLパターン、表示・並べ替えなどの設定

自動固定を有効にした場合、本拡張機能は登録ルールとの照合と不足タブの復元に必要な範囲で、開いているタブを確認します。

本拡張機能は、Webページ本文、フォームへの入力内容、Cookie、パスワードを読み取りません。利用者がJSONバックアップを作成した場合、そのファイルは利用者の端末へダウンロードされます。

2. 利用目的

取り扱う情報は、タブの整理、URL一覧とタブグループの保存・復元、自動固定ルールの適用、および利用者が有効にした同期機能の提供に限って利用します。広告、行動分析、プロファイリング、情報の販売には利用しません。

3. 保存先と共有先

  • 端末内: URL一覧、保存グループ、操作の取り消し情報は、Chrome拡張機能のローカルストレージに保存します。
  • Chrome同期: 設定はChromeの同期ストレージに保存します。Chromeの同期が有効な場合、GoogleのChrome同期サービスを通じて同期されます。
  • Google Drive（任意）: 利用者が設定画面から接続し、Drive同期を有効にした場合に限り、URL一覧と保存グループをGoogle Drive APIの本拡張機能専用領域（appDataFolder）へ送信・保存します。通常のDriveファイルやフォルダーにはアクセスしません。

開発者が運営するサーバー、広告サービス、解析サービスへタブ情報や設定を送信しません。Chrome同期またはDrive同期を使う場合は、それぞれの機能に必要な情報がGoogleへ送信されます。

4. 保存期間と削除

端末内の保存URLと保存グループは、本拡張機能の画面から削除できます。設定の同期データはChrome同期の設定に従って管理されます。

Drive同期を切断すると、その後の自動同期を停止します。切断だけでは、すでにDriveへ保存されたデータは削除されません。保存済みデータはGoogle Driveの「設定」から「アプリを管理」を開き、本拡張機能の非表示アプリデータを削除してください。

ダウンロードしたJSONバックアップは、利用者が端末から削除するまで残ります。

5. 権限の利用目的

  • tabs、tabGroups: タブとタブグループを整理、保存、復元するため
  • storage: URL一覧、グループ、設定を保存するため
  • contextMenus: 右クリックメニューを表示するため
  • sidePanel: 本拡張機能の画面をサイドパネルに表示するため
  • identity: 利用者が選択した場合にGoogleアカウントでDrive同期を認証するため
  • https://www.googleapis.com/*: 利用者が有効にしたDrive同期でGoogle APIと通信するため

6. Google APIデータの利用

Google APIから受け取った情報の利用は、Chrome Web Store User Data Policy（Chrome Web Storeユーザーデータポリシー）のLimited Use要件に従います。

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

7. ポリシーの変更

本拡張機能の機能や情報の取り扱いを変更する場合は、本ポリシーを更新します。情報の利用方法に変更がある場合は、拡張機能内でも説明します。

8. 問い合わせ

本ポリシーまたは本拡張機能については、Chrome Web StoreのTab Listing掲載ページに記載するサポート窓口からお問い合わせください。

本ポリシーはTab Listingの現在の実装を前提にしています。更新日: 2026年10月5日
